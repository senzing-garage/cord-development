# cord-development

If you are beginning your journey with [Senzing],
please start with [Senzing Quick Start guides].

You are in the [Senzing Garage] where projects are "tinkered" on.
Although this GitHub repository may help you understand an approach to using Senzing,
it's not considered to be "production ready" and is not considered to be part of the Senzing product.
Heck, it may not even be appropriate for your application of Senzing!

:warning: **WARNING: cord-development is still in development** :warning:
_At the moment, this is "work-in-progress" with Semantic Versions of `0.n.x`._
_Although it can be reviewed and commented on, do not use it yet._

## Overview

At present this repository holds only the standard Senzing Garage repository
scaffolding: the community artifacts and the standard workflow set.
